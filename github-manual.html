① 初回設定

GitHubへアップする前に、最初の1回だけユーザー名とメールアドレスを設定します。

初回設定 
git config --global user.name "あなたの名前"
git config --global user.email "your@email.com"

# 設定確認
git config --global --list
すでに設定済みの場合は、毎回実行しなくて大丈夫です。

② GitHubからクローンする場合

GitHub上にあるリポジトリをMacへコピーする場合に使います。

クローン 
git clone https://github.com/ユーザー名/リポジトリ名.git
cd リポジトリ名
すでにローカルフォルダを作成して使っている場合は、cloneは不要です。

③ ローカル変更をGitHubへ反映

普段いちばん使う基本の流れです。

基本の反映コマンド 
# 状態確認
git status

# 変更を追加
git add .

# 変更内容を記録
git commit -m "update"

# GitHubへ反映
git push origin main
ブランチ名が main ではなく master の場合は、最後を git push origin master に変更します。

④ HTML / CSS / JSだけの静的サイトの場合

以下のような構成なら、基本的にnpmやbuildは不要です。

静的サイトの例 
yurayura/
├── index.html
├── style.css
├── script.js
└── images/

この場合は、そのままGitへ反映します。

静的サイトのアップロード 
git status
git add .
git commit -m "update"
git push origin main

⑤ npmを使うプロジェクトの場合

React、Vite、Next.jsなどの場合は、package.jsonがある場所でnpmコマンドを実行します。

npmプロジェクト確認 
# 現在地確認
pwd

# 中身確認
ls -la

# package.jsonがあるか確認
ls package.json
npm install / build 
npm install
npm run build
package.json がない場所で npm install や npm run build を実行すると、ENOENTエラーになります。

⑦ Git管理を解除したい場合

MacではWindowsの rmdir /s /q は使いません。

Mac版 .git 削除 
# 指定フォルダのGit管理を解除
rm -rf website/.git

# 現在のフォルダのGit管理を解除
rm -rf .git
rm -rf は強力な削除コマンドです。実行前に必ず pwd と ls -la で場所を確認してください。

⑧ エラー一覧

MacでGitHubやnpmを使う時によく出るエラーを、原因と対処法で一覧化しています。

エラー 主な原因 対処法
npm
ENOENT		 package.json がない場所で npm コマンドを実行している。 pwd と ls -la で現在地を確認。package.json がある場所へ移動。
cd
no such file or directory		 フォルダ名が違う。日本語パスや濁点の文字コードがずれている。 Finderからフォルダをターミナルへドラッグ＆ドロップする。
git
not a git repository		 .git がないフォルダで git コマンドを実行している。 ls -la で .git を確認。なければ正しいリポジトリへ移動。
git
nothing to commit		 変更がない、またはすでにcommit済み。 git status で状態確認。問題なければpushへ進む。
git
rejected / non-fast-forward		 GitHub側にローカルより新しい変更がある。 git pull origin main で取り込んでから再度push。
git
src refspec main does not match any		 mainブランチがない、またはまだcommitしていない。 git branch でブランチ名確認。必要なら初回commitを作成。
auth
Authentication failed		 GitHubの認証情報が古い、または権限がない。 GitHub Desktop、gh CLI、またはPersonal Access Tokenで再認証。
Mac
rmdir: failed to remove '/s'		 Windows用コマンドをMacで実行している。 Macでは rm -rf フォルダ名 を使う。

⑧ よくあるエラーと原因

npm error ENOENT

package.json がない場所で npm コマンドを実行しています。

確認方法 
pwd
ls -la
ls package.json

cd: no such file or directory

指定したフォルダが存在しない、または日本語パスの入力がずれている可能性があります。

Macでは、Finderのフォルダをターミナルへドラッグ＆ドロップすると正確なパスを入力できます。

git push できない

リモート接続、ブランチ名、ログイン認証のどれかが原因になっていることが多いです。

確認コマンド 
git remote -v
git branch
git status

作業前チェックリスト

  • フォルダ内を ls -la で確認した
  • npmを使う場合は package.json がある場所で実行した
  • HTML/CSS/JSだけなら npm run build は不要
  • GitHubへ反映前に git status を確認した
